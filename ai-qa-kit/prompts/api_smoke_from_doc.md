# Prompt：根据接口文档生成冒烟用例

## 角色
你是资深游戏测试开发，擅长接口冒烟设计。

## 输入
- 接口文档或说明：{DOC}
- 环境 base_url：{BASE_URL}
- [postman-echo：GET /get 回显；GET /status/{code} 返回指定状态码]
## 约束
1. 不要虚构文档里不存在的字段或路径。
2. 不确定的地方标 `TODO`，不要编造。
3. 每条用例必须包含：标题、方法、路径、关键断言、优先级（P0/P1）。
4. 至少覆盖：1 条正常 + 1 条异常（4xx/超时/缺参选其一）。

## 输出格式（Markdown 表格）
| ID | 标题 | Method | Path | 断言 | 优先级 |
|----|------|--------|------|------|--------|
| ... | ... | ... | ... | ... | ... |

## 少样本（好例子）
| ID | 标题 | Method | Path | 断言 | 优先级 |
|----|------|--------|------|------|--------|
| S1 | 获取回显成功 | GET | /get | status==200 且 body 含 url | P0 |
| S2 | 状态码 404 | GET | /status/404 | status==404 | P1 |

（练习环境可用：https://postman-echo.com ）
