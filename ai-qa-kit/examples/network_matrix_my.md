# 网络异常场景矩阵（人工定稿 v2）

- 来源 Prompt：`ai-qa-kit/prompts/network_matrix.md`
- 业务动作：肉鸽「战斗结束领取奖励」
- 客户端：Unity 手游
- 网络环境：4G 弱网（部分场景扩展至 WiFi / 飞行模式 / 极慢网）
- 状态：人工定稿（含 v1 + 新增场景）

---

## 一、客户端 / 网络异常（基础）

| ID | 场景 | 时机 | 操作步骤 | 期望行为 | 优先级 |
|----|------|------|----------|----------|--------|
| N1 | 领奖前断网 | 请求前 | 4G 弱网下战斗胜利 → 结算页出现 → 开飞行模式 → 点「领取奖励」 | 明确提示网络不可用；不无限转圈；不扣本地进度；可关闭提示后继续查看结算信息 | P0 |
| N2 | 领奖请求超时 | 请求中 | 弱网工具将领奖接口延迟至超过客户端超时（如 30s）→ 点「领取奖励」 | 超时后有提示；提供「重试」；未成功前不显示已领取；本地战斗结果不丢 | P0 |
| N3 | 领奖响应中断 | 请求中 | 点「领取奖励」后，响应返回一半时断网（弱网丢包/断连） | 不崩溃；不卡死在领奖界面；标记为「领取结果未知」或失败；可重试；TODO：幂等防重复发奖 | P0 |
| N4 | 弱网重复点击领取 | 请求中 | 4G 弱网下连点「领取奖励」3～5 次 | 按钮防抖或置灰；同一场战斗奖励只到账一次；TODO：幂等 key 规则 | P0 |
| N5 | 领奖成功后断网 | 响应后 | 领奖成功提示出现后立刻断网 → 退出再进游戏 | 奖励已入账且与服务器一致；重进后不回滚；图鉴/货币/背包显示正确；TODO：离线缓存同步策略 | P1 |
| N6 | 断网后恢复再领奖（手动） | 恢复重连 | 领奖前断网失败 → 关飞行模式恢复 4G → 再次点「领取奖励」 | 手动重试成功；奖励正常发放；无重复弹窗；无请求风暴 | P0 |
| N7 | 领奖成功但进下一层失败 | 响应后 | 领奖成功 → 点「进入下一层/继续」时弱网超时 | 奖励不回滚；明确提示下一关加载失败；可重试进入；不丢局内进度；TODO：关卡入口与领奖接口是否同一事务 | P1 |
| N8 | 后台切前台时领奖 | 请求中 | 点领取后立刻切到后台 10s → 再回前台 | 不崩溃；请求结果正确处理；界面状态与真实到账一致；TODO：Unity 生命周期下请求取消策略 | P1 |
| N9 | 4G 与 WiFi 切换 | 请求中 | 领奖请求发出瞬间从 4G 切到 WiFi（或反向） | 不崩溃；最终成功或可理解失败提示；可重试；不出现「已领取但无奖励」 | P1 |
| N10 | 长时间弱网挂结算页 | 请求前 | 弱网停留在战斗结算页 5～10 分钟再点领取 | Token/会话不过期或友好提示重新登录；点领取仍可走通或明确失败原因；不 silent fail | P2 |

## 二、客户端稳定性 / UI 干扰（新增）

| ID | 场景 | 时机 | 操作步骤 | 期望行为 | 优先级 |
|----|------|------|----------|----------|--------|
| N11 | 领奖过程游戏闪退 / 杀进程 | 请求中 / 响应半路 | 点「领取奖励」，请求发出后或响应返回途中强杀游戏进程 → 重启登录 | 奖励不重复发放；可重试领取；本地战斗结算数据保留；服务端幂等校验通过；TODO：杀进程时机需记录 requestId | P0 |
| N12 | 结算页内存溢出 / 卡顿卡死 | 请求前 | 结算页停留较久、频繁切页面后点「领取奖励」，观察是否 UI 卡死 | 若异常则弹窗提示；可退出结算页；无资源错乱、无黑屏死锁；TODO：需 Profiler 配合定位 | P2 |
| N13 | 领奖弹窗被其他弹窗覆盖 | 请求中 | 点领取进入 loading 期间，自动弹出签到 / 活动弹窗遮挡结算 | 领奖请求不中断；loading 正常；遮挡弹窗关闭后正确展示领奖结果（成功/失败） | P1 |
| N14 | 领奖时触发版本更新弹窗 | 请求中 | 领奖请求进行中弹出强制更新弹窗 | 请求合理终止或安全结束；更新完成后回到结算页可重试领奖；不出现重复发奖；TODO：强制更新与在途请求取消策略 | P1 |

## 三、后端 / 服务侧异常（新增）

| ID | 场景 | 时机 | 操作步骤 | 期望行为 | 优先级 |
|----|------|------|----------|----------|--------|
| N15 | 领奖接口 500 / 服务报错 | 请求中 | 点「领取奖励」，服务端内部异常返回 5xx / 业务错误码 | 友好失败提示；支持重试；不扣领奖次数；不重复发奖；日志可定位 traceId | P0 |
| N16 | 领奖时账号异地登录被顶下线 | 请求中 | 领奖过程中另一设备登录同一账号，当前设备被踢下线 | 领奖请求终止；提示账号下线/已在其他设备登录；重新登录后可重新领取；无重复到账 | P0 |
| N17 | 背包满无法领取奖励 | 响应后 | 领奖请求成功，但背包已达容量上限，资源无法存入 | 提示背包已满；奖励进入缓存/邮件待领取；清理背包后可补发；不丢失、不重复 | P0 |
| N18 | 领奖道具存在时效 / 过期限制 | 响应后 | 领取限时道具成功 → 断网重登 → 观察倒计时 | 离线时间计算正确；不会永久有效；不会异常直接消失；TODO：以服务器时间为准还是本地时间 | P1 |

## 四、网络细分边界（新增 / 补充）

| ID | 场景 | 时机 | 操作步骤 | 期望行为 | 优先级 |
|----|------|------|----------|----------|--------|
| N19 | 飞行模式恢复后自动重试领奖 | 请求前断网 → 恢复 | 领奖前开飞行模式失败 → 长时间（如 1～3 分钟）后恢复网络，**不手动点重试** | 若产品设计支持自动重试：网络恢复后自动发起或提示一键重试；不重复发奖；TODO：无自动重试则标为已知限制 | P1 |
| N20 | 网络频繁来回切换 | 请求全过程 | 领奖全程反复切换 WiFi → 4G → 飞行模式 → 4G（≥3 次） | 不崩溃；最终状态与服务器一致；可重试；无重复请求风暴；无「已领无奖」 | P1 |
| N21 | 极慢网速完整走完领奖（1KB/s） | 全程 | 弱网工具限速 1KB/s，未触发超时前提下完成领奖全流程 | 流程可走完或给出可理解等待/失败提示；不卡死；loading 有反馈；TODO：超时阈值需与产品对齐 | P2 |

## 五、业务流程边界（新增）

| ID | 场景 | 时机 | 操作步骤 | 期望行为 | 优先级 |
|----|------|------|----------|----------|--------|
| N22 | 重复进入结算页（多次返回战斗结算） | 请求前 | 领完奖励退出结算 → 再次打赢战斗 → 重复进入结算页领奖 | 每场战斗领奖次数正常扣除；不会无限领取；历史战斗不可重复领 | P0 |
| N23 | 领奖后返回主城，跨副本再次触发结算领奖 | 响应完成后 | 战斗 A 领奖完成 → 回主城 → 进入战斗 B 结算领奖 | 单次战斗仅可领奖一次；战斗 B 奖励独立发放；不会重复产出战斗 A 奖励 | P0 |
| N24 | 领奖时触发服务器维护 | 请求中 | 领奖中途服务器停服维护，连接断开 | 领奖未成功完成；维护结束登录后可重新领取；无重复发奖；有维护提示 | P1 |

## 评审备注

### P0 必测清单（共 12 条）

N1、N2、N3、N4、N6、N11、N15、N16、N17、N22、N23

### 与自动化 / Mock 的对应（能测的先测）

| 场景类型 | 建议手段 |
|----------|----------|
| 断网 / 超时 / 重试 | `NetworkSimulator`、`HttpClient` retry、mock Timeout |
| 500 服务错误 | Mock 接口返回 500，或 Charles 映射 |
| 重复点击 / 幂等 | 接口自动化连发 + 查账；客户端日志 requestId |
| 闪退 / 杀进程 | 真机 + 日志；自动化难，偏手工/专项 |
| UI 遮挡 / 强制更新 | Unity 手工或 UI 自动化；需专用测试包 |
| 背包满 / 异地登录 | 需测试账号与 GM/造数支持 |
| 极慢网 / 低电量 | 弱网工具 + 真机专项 |
