# 第 10 课笔记（请用自己的话补全）

## 1. 失败摘要解决什么问题？为什么不能代替真实测试红灯？

摘要只是「人话说明」；红灯仍由 `failed > 0` / pytest 决定。  
 摘要写错了也不能把失败改成成功。

## 2. 没有 API Key 时，平台怎么生成摘要？有 Key 时呢？


| **情况**            | **谁生成**                   |
| ----------------- | ------------------------- |
| 无 API Key         | **本地规则**（抽 FAILED、assert） |
| 有 `QA_AI_API_KEY` | 优先尝试**大模型**，失败则回退规则       |


## 3. 为什么摘要失败也不能影响 `POST /api/jobs/{id}/result` 交卷？

因为摘要是辅助能力：  
 交卷（`passed/failed/total`）必须先落库；摘要挂了最多显示跳过，不能让整次测试结果丢了。
