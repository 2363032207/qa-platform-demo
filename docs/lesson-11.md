# 第 11 课笔记（请用自己的话补全）

## 1. 质量门禁和「跑一下 pytest」有什么区别？

- pytest：告诉你哪些用例挂了
- 门禁：根据结果做放行决定（能不能合代码），并给出统一规则与退出码

## 2. 为什么 AI 失败摘要不能改变门禁结论？

摘要只是解释失败原因，可能猜错；门禁必须只认真实 `failed/total`。若摘要能改结论，就会出现「看起来像环境问题就放行」的误放。

## 3. PR 时 CI / 门禁红了，应不应该合入？为什么？

不可以，因为代表用例出现问题
