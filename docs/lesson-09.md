# 第 9 课笔记（请用自己的话补全）

## 1. 看板页面和 Swagger `/docs` 有什么区别？


|      | **看板** `/` | **Swagger** `/docs` |
| ---- | ---------- | ------------------- |
| 给谁看  | 人（一眼看通过率）  | 调试接口的人              |
| 能做什么 | 看任务、状态、通过率 | 创建任务、查详情、手动交卷       |


## 2. 通过率是怎么算出来的？

通过率 = 所有已有 result 的任务里

         Σ passed  ÷  Σ total

## 3. 为什么看板要读平台里的 result，而不是直接看 Agent 终端？

result可以更清晰的看到
