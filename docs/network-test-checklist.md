# 网络异常测试清单（练习版）

## 自动化（HttpClient / pytest）


| ID  | 场景           | 怎么测                                  | 期望                      |
| --- | ------------ | ------------------------------------ | ----------------------- |
| A1  | 模拟断网         | `NetworkSimulator.set_offline(True)` | 抛 `NetworkOfflineError` |
| A2  | 超时重试成功       | mock 第 1 次 Timeout，第 2 次 200         | 最终成功，请求 2 次             |
| A3  | 重试耗尽         | mock 连续 Timeout，`retry=1`            | 抛 Timeout，请求 2 次        |
| A4  | HTTP 4xx/5xx | 真实请求 `/status/404`                   | **不重试**，直接返回 404        |


## 真机 / 手工（游戏向）


| ID  | 场景   | 操作                   | 期望          |
| --- | ---- | -------------------- | ----------- |
| M1  | 飞行模式 | 进游戏前开飞行模式            | 明确断网提示      |
| M2  | 弱网   | Charles/Clumsy 加延迟丢包 | 超时可重试，不崩    |
| M3  | 恢复网络 | 断网后关闭飞行模式            | 可重试成功或自动恢复  |
| M4  | 重复点击 | 弱网下连点登录/领取           | 不重复扣费/不重复发奖 |




## 分工

- **编辑器 Mock**：`NetworkSimulator` — 快、可自动化
- **真机飞行模式**：验收真实体验
- **弱网工具**：延迟、丢包、超时

A1和M4为P0这些都会严重影响到玩家体验和游戏进程，**A2（超时重试成功）**——领奖弱网很常见。
